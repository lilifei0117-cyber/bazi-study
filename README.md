# 知序 · 八字基础刷题

一款无需安装即可使用的八字基础知识刷题工具，内置 320 道单选与多选题，包含顺序练习、随机十题、错题重练和二十五题模拟考试。

## 功能

- 按天干、地支、五行、十神、合冲刑害、藏干、排盘、关系判断和综合分类练习
- 关系判断专项新增 70 道六合、六冲、六害、三合、三会与相刑题
- 自动记录掌握情况与错题，刷新页面后仍会保留
- 模拟考试结果、分类得分与错题回顾
- 支持键盘操作和手机端布局

## 本地使用

直接打开 `index.html`，或使用任意静态文件服务器运行本目录。

## 在线访问

发布后可通过 GitHub Pages 直接使用。
